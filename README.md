# TenTen Reward Reserve — web

Read-only page for the TEN Reward Reserve V1 on Robinhood Chain, built as a native extension of
tentencapital.net (`/reward-reserve/`). No wallet connection, no signing, no transactions:
holders check a public address here and claim themselves on Blockscout.

- `reward-reserve/` — the static page (drop-in folder)
- `reward-reserve/INTEGRATION.md` — how to publish it and connect Indexer / epoch artifacts
- `reward-reserve/tests/` — headless render and safety tests (`npm test`)
